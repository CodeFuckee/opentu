# Smart Cutout Capability Delta

## ADDED Requirements

### Requirement: 点提示抠图推理服务

系统 SHALL 提供登录用户可用的服务端图像分割推理：用户提交一张图片后，通过在图上标注正/负点（可选框）逐步细化目标掩码，并取得目标掩码图。推理入口须经 edge function 鉴权（有效用户 JWT），推理容器不得直接暴露给内网客户端。

#### Scenario: 首次编码会话

- **WHEN** 登录用户在图片编辑器中打开抠图面板
- **THEN** 前端将缩放至长边不超过 1024px 的图片提交编码，系统返回会话标识与图片尺寸，后续点击复用该会话

#### Scenario: 正负点细化掩码

- **WHEN** 用户在图片上添加一个或多个正点/负点并触发分割
- **THEN** 系统基于会话返回对应掩码（PNG），前端以半透明覆盖层实时展示，且单次点击响应在性能预算内（GPU ≤300ms / CPU ≤1s）

#### Scenario: 会话过期或超量

- **WHEN** 会话超过 10 分钟未使用或服务端会话池超量淘汰
- **THEN** 后续分割请求返回明确错误，前端自动重新编码图片并重放当前点集，用户无需重新操作

#### Scenario: 未登录拒绝

- **WHEN** 请求未携带有效用户 JWT
- **THEN** edge function 返回 401，不转发至推理服务

### Requirement: 抠图结果合成与插入

系统 SHALL 在用户确认掩码后，将原图与掩码合成为透明背景 PNG，并可经图片编辑器现有"插入画布/保存"链路交付，合成过程在浏览器内完成且不依赖 secure context 能力。

#### Scenario: 确认抠图并插入画布

- **WHEN** 用户对掩码预览满意并确认插入
- **THEN** 系统以原图分辨率合成透明底 PNG，作为新图片元素插入当前画布

#### Scenario: 跨源或加载失败的原图

- **WHEN** 原图因跨源限制或缓存失效无法读取像素
- **THEN** 系统以匿名跨源方式重载重试；仍失败时向用户明确提示失败原因，不产出损坏结果

### Requirement: 推理服务降级与可观测

系统 SHALL 在 GPU 显存不足时自动降级 CPU 推理而不中断服务，并对外如实上报当前推理设备；服务须提供健康检查端点用于部署验证与巡检。

#### Scenario: 显存不足自动降级

- **WHEN** GPU 编码因显存不足失败
- **THEN** 服务自动以 CPU 重新编码并在响应中标记设备为 CPU，用户仅感知到首次分析变慢

#### Scenario: 服务不可用的前端提示

- **WHEN** 推理服务不可用或请求超时
- **THEN** 前端给出明确的失败提示并允许用户退出抠图面板，画布其他功能不受影响

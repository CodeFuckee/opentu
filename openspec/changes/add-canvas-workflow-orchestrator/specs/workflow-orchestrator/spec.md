# workflow-orchestrator 能力修订(承载面迁移:WinBox → 主画布)

## MODIFIED Requirements

### Requirement: 编排画布与节点编辑(改为:主画布原生节点元素)

工作流节点与连线成为主画布原生元素:节点可选中/拖动/框选/对齐/撤销,双击进入参数编辑态;连线从节点输出端口拖出生成并即时做类型校验;编排数据随画板持久化与云同步,一张画布可共存多个工作流(按连通图自动划分)。

#### Scenario: 在主画布上搭建生图工作流

- **When** 用户从工具箱添加「提示词」「文生图」「存素材库」节点到主画布,从文生图左端口拖出连线到提示词节点,双击提示词节点填写文本,点文生图节点 ▶
- **Then** 提示词节点与文生图节点依次进入运行态,生成图自动落在文生图节点右侧成为普通图片元素,素材库同步可见;节点与连线随画板保存,刷新后完整恢复

#### Scenario: 节点编辑与画布交互隔离

- **When** 用户单击节点并拖动
- **Then** 节点作为元素被选中并移动(不触发参数编辑);双击节点才进入参数编辑态,编辑期间画布快捷键挂起,ESC 退出

#### Scenario: 非法连线即时拒绝

- **When** 用户从「文生图」输出端口拖到「提示词」文本端口
- **Then** 连线不生成并提示端口类型不匹配

### Requirement: DAG 执行与运行态反馈(继承 M1 语义,载体改为画布元素)

运行按连通图划分工作流并 DAG 执行;节点与连线在画布上实时染色;失败节点 ▶ 重跑自身及上游;运行期间结构编辑锁定。

#### Scenario: 连通图自动划分与运行全部

- **When** 画布上存在互不相连的两簇工作流节点,用户点击工具条「运行全部」
- **Then** 两簇各自独立按 DAG 执行,互不依赖的节点并行,节点/连线状态实时染色

### Requirement: 生成物自动落画布

生成/输出节点完成后,生成图自动作为普通图片元素落在对应节点右侧(网格排布),可独立移动、进编辑器、归档。

#### Scenario: 生成图落节点旁

- **When** 文生图节点(设定 4 张)执行完成
- **Then** 4 张图以网格排布落在该节点右侧画布上,与节点无绑定关系(可单独拖动/删除/编辑)

### Requirement: M1 迁移(旧编排图导入)

WinBox 版下线;旧 IndexedDB 编排图提供「导入到画布」:图节点/连线/参数批量转为画布元素,几何沿用原坐标。

#### Scenario: 旧图导入主画布

- **When** 用户在旧图导入列表选择一张 M1 保存的工作流执行导入
- **Then** 画布出现对应节点与连线元素,参数完整,可直接运行

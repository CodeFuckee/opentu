# workflow-orchestrator 能力增量

## ADDED Requirements

### Requirement: 编排画布与节点编辑

用户可从工具箱打开「工作流编排」WinBox 画布,添加节点(M1:提示词/参考图/模型与参数/文生图/基于图生成/插入画布/存素材库/预览)、在输出端口与输入端口间连线、在参数面板编辑未连线字段、删除节点与连线,并把整张图保存为具名工作流。

#### Scenario: 搭建生图工作流

- **When** 用户添加「提示词」「模型与参数」「文生图」「存素材库」四个节点并按
  提示词→文生图、模型→文生图、文生图→存素材库连线,填写提示词后点保存
- **Then** 图 JSON 以当前 schemaVersion 持久化,工作流列表出现该具名工作流,刷新后可重新打开且节点/连线/参数完整

#### Scenario: 非法连线的编译期拒绝

- **When** 用户把「文生图」的输出连到「提示词」的文本输入端口并点运行
- **Then** 编译期校验失败,提示类型不匹配并定位到该连线,不进入执行

### Requirement: DAG 执行与运行态反馈

运行时把节点图编译为依赖步骤并执行:依赖未就绪的节点等待,就绪节点执行;每个节点实时显示 pending/running/completed/failed 状态;失败节点标红且可单点重跑(其下游一并重跑)。

#### Scenario: 按依赖顺序执行并在 UI 染色

- **When** 用户运行「提示词→文生图→存素材库」工作流
- **Then** 文生图节点先进入 running(生成任务出现在任务队列),完成转 completed 后存素材库节点才开始,全程节点描边色与状态一致,全部完成后素材库出现生成图

#### Scenario: 失败节点单点重跑

- **When** 文生图节点执行失败(如模型服务 5xx)
- **Then** 该节点标红并显示错误摘要,修复条件后可对该节点重跑,仅重跑该节点及其下游

### Requirement: 结果落地

输出类节点把生成结果落地:插入画布(走 ai-outputs 直链,网格排布)、存素材库(复用归档链路)、节点内预览。

#### Scenario: 生成图落地素材库与画布

- **When** 文生图节点产出 4 张图且同时连接「存素材库」与「插入画布」
- **Then** 素材库新增 4 条素材、画布出现 4 张图(网格排布),两个输出节点各自标记完成

### Requirement: 持久化与云同步

编排图 JSON 版本化存储于本地,并复用既有 workflow 云同步通道跨设备同步;旧版本图在读取时按迁移函数升级。

#### Scenario: 跨设备恢复编排图

- **When** 设备 A 保存工作流后,设备 B 以同账号登录并触发云同步
- **Then** 设备 B 的工作流列表可见该图,打开后节点/连线/参数与设备 A 一致

### Requirement: 工具箱入口

「工作流编排」作为内置工具出现在工具箱抽屉,点击打开 WinBox 画布窗口,与素材库等工具窗并存且互不影响。

#### Scenario: 从工具箱打开编排画布

- **When** 用户打开工具箱抽屉并点击「工作流编排」
- **Then** 弹出 WinBox 画布窗口,可与其他工具窗并存,关闭后状态保留至下次打开
